## 一、三维标签体系

### 维度① 地块类型（行业）
| 大类 | 典型行业（本项目覆盖） |
|---|---|
| 机动车零部件 | 气缸套、车轮、车桥、铸造配件、机械加工 |
| 通用机械制造 | 重工、管桩附件、机电 |
| 表面处理相关 | 电镀/涂装（常并入汽车零部件产污环节） |
> 本项目聚焦"汽车零部件及配件制造"单一行业，特征污染物高度同源（石油烃 + 苯系物 + 特定重金属），是提炼行业范式的最佳样本。

### 维度② 问题类型（= 土壤调查报告红线主分类）
1. **特征污染物识别类** — 行业产污环节不清 / 监测因子漏项 / 周边对照因子不全
2. **监测方案类** — 布点代表性 / 采样深度分层 / 采样频次 / 功能区覆盖
3. **数据分析评价类** — 检出即影响判定 / 内外关联性 / 占标率与检出率排序
4. **超标原因论证类** — 高背景值 vs 生产影响 / 地质成因佐证
5. **报告规范性类** — 背景值/区域对照值引用 / 不确定性分析 / 针对性管理对策
6. **样品追溯类** — CMA 章 / 原始记录 / 样品链（可接 环境实验「一码到底」）

### 维度③ 红线判据（每个问题类型下的「锚点」，用来从报告里捡案例）
- **检出即影响**：石油烃(C10-C40)、苯并[a]芘 一旦检出，即判为生产活动影响（专家口径，直接定性）
- **背景值比对**：评价必须参照区域对照值/背景值，不能单看 GB 36600 筛选值；超标须用高背景值分析+证明资料解释
- **内外关联**：同一污染物地块内 vs 周边土壤浓度必须做比较，分析关联性
- **占标排序**：按检出率、占标率排序，前几名列为管理部门重点监管污染物
- **深度分析**：从特征污染物检出、占标情况反推企业生产活动影响；结合水文地质+工艺+产污环节
- **不确定性**：报告须含不确定性分析章节
- **可追溯**：原始数据须盖 CMA 章、样品链完整（接一码到底）

| S06 | 样品 CMA 章与原始记录追溯（接一码到底） | 样品追溯 | 骨架 |

### S03 / S04 / S06 信号速记（待扩成完整样例）
- **S03**：专家要求每个地块增加"地块内外关联性分析"章节——同一污染物在地块内、企业周边、农田的浓度值并列比较，判断污染是否外溢。缺此章节=报告不完整。
- **S04**：专家明确"增加不确定性分析"——布点密度、历史资料完整性、背景值代表性、检测下限带来的判定局限，须在第八章单列。
- **S06**：原始数据须以"附件5 原始数据（盖 CMA 章）"形式归档；样品从采到测的链条（采样记录→交接→分析）须可回溯，与 环境实验 一码到底同源。
