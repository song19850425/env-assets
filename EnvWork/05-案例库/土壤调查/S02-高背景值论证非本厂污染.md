# S02 超筛选值但源于高背景值，如何论证"非本厂污染"

- 问题类型 / 覆盖地块类型 / 难度：超标原因论证类 / 机动车零部件·机械制造（重金属类） / ★★★
- 来源：某省土壤调查项目（脱敏，无企业名 / 宗地码 / 地市）

## 信号清单（怎么一眼看出）
- 某个重金属（锰、锌、铬、钼等）点位**超 GB 36600 筛选值**，但企业工艺上几乎不产生/使用该元素；
- 周边土壤、甚至更远的农田/背景点**同样超标**，且浓度梯度不随距离企业衰减；
- 区域地质资料表明该元素在本区成土母岩中本底偏高；
- 初稿直接写"企业污染导致超标"被专家退回，要求"用高背景值分析+证明资料"解释。

## 判据锚点（评审红线/量化依据）
- **专家口径（原话级）**：超标原因来源于**高背景值的分析及证明资料**——初稿缺此论证被退回。
- 评价必须"参照不同区域的背景值进行评价"（专家意见第 2 条）：用区域对照值 / 背景值，而非单看一类筛选值。
- 关键判据：**内外浓度梯度**。若企业内 > 周边 > 农田 且递减排，倾向生产影响；若周边/农田已高、企业内无显著抬升，倾向高背景值。

## 整改/论证路径
1. 调取**区域对照值、背景值、周边同母岩区历史数据**作为比对基准；
2. 做**地块内外关联性分析**（接 S03）：并列企业内、企业周边、农田同一元素浓度；
3. 写"超标原因"小节：引用地质成因/成土母岩资料，证明超筛选值源于**自然高背景**，非企业生产输入；
4. 给出"风险可接受"结论，并附不确定性说明（接 S04）；
5. 留痕：所有背景值来源资料入附件，备查。

## 评审口径（专家为什么卡这一条）
- 专家意见第 2、7 条直指：不能单看筛选值，要"参照区域背景值"且"超标原因须高背景值证明"；
- 目的：防止把**天然高背景**误判为"企业污染"，既冤枉企业、也误导管理对策。

## 行业分布
- 锰、锌、铬、钼 在汽车零部件/机械制造行业高频出现（机加工切削液、合金原料带入），但本区成土母岩本就富锰锌，**最易踩 S02**；
- 本项目多个地块"锰"为共有特征污染物，且周边土壤同步检出，典型高背景值场景。

## 易混淆
- 与 **S01（检出即影响）** 是"非此即彼"的两条线：石油烃/苯并芘走 S01，重金属走 S02（除非有强工艺来源证据）；
- 与 **S03（内外关联）** 强耦合：S02 的论证几乎全靠 S03 的内外浓度比较支撑。

## 沉淀（进哪条产品线 / 可写什么）
- 可写公众号文：《这块地超筛选值，但真不是厂的锅——高背景值怎么证明》；
- 可进「土壤调查评审自查一页纸」B 方案"超标原因论证"卡片；
- 接 CMA 核查表"报告结论合规"红线条。
