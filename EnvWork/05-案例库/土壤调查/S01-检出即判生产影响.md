# S01 石油烃/苯并[a]芘检出即判"生产活动影响"

- 问题类型 / 覆盖地块类型 / 难度：数据分析评价类 / 机动车零部件·机械制造 / ★★
- 来源：某省土壤调查项目（脱敏，无企业名 / 宗地码 / 地市）

## 信号清单（怎么一眼看出）
- 报告里把"石油烃(C10-C40)、苯并[a]芘"的**任何检出**直接写成"表明存在企业生产活动影响"；
- 没有做"是否背景值/地质成因"的鉴别，就定性归因；
- 章节表述通常是"根据题干检出即判定为……影响"，全文一致套用。

## 判据锚点（评审红线/量化依据）
- **专家口径（原话级）**：石油烃、苯并[a]芘**只要检出，即为生产活动的影响**——这是省级评审对该类指标的刚性判定，不依赖浓度高低。
- 依据：这两类污染物在自然地表中背景极低、且与企业机加工/涂装/热处理工艺强相关，故"检出≈人工来源"。
- 注意区分：重金属（锰、锌等）**不适用**此口径——它们常源于成土母岩高背景，须走 S02 的高背景值论证。

## 整改/论证路径
- 写报告时：**凡石油烃、苯并[a]芘检出，直接定性生产影响**，不必绕弯；
- 但要注意：定性之后仍需在"超标原因/贡献分析"里结合工艺环节（如机加工润滑油、涂装废气沉降）说明来源路径，否则专家会追"S06 深度分析"；
- 若检出但**未超筛选值**，仍要写"检出即影响"表述，只是结论是"风险可接受"，不能省略定性句。

## 评审口径（专家为什么卡这一条）
- 专家原意见第 3 条即此条，要求"已修改全文相关表述"——说明初稿没统一口径，被退回；
- 这是省级调查"宁可从严"的口径：把人工特征污染物检出直接挂钩企业生产，便于后续管理对标。

## 行业分布
- 机动车零部件（气缸套、车轮、车桥）、通用机械制造、表面处理——凡有"润滑油+涂装+热处理"环节的行业都易踩。
- 本项目 13 个地块中，石油烃为**全域共有特征污染物**，苯并[a]芘在铸造/重工类地块高频检出。

## 易混淆
- 与 **S02（高背景值论证）** 反着来：S02 是"超标但非本厂"，S01 是"检出即本厂影响"。判断顺序：先看污染物种类→石油烃/苯并芘走 S01，重金属走 S02。
- 与 **S03（内外关联）** 并发：S01 定性后，常用 S03 的内外浓度比较佐证"影响范围"。

## 沉淀（进哪条产品线 / 可写什么）
- 可写公众号文：《专家一句话：石油烃检出了，就是你们厂的影响》（对标安阳 C 方案）；
- 可进 环境实验「土壤调查评审自查一页纸」B 方案判据卡；
- 接 CMA 核查表"报告表述合规"红线条。
