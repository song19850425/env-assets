# 03 非标方法走了"验证"，评审开不符合

- 域 / 红线类型 / 难度：合规红线 / 方法验证 / 确认 / ★★★
- 日期：2026-05 / 脱敏场景：某机构承接新污染物（非标方法）检测，迎 CMA 评审

## 背景
客户要测一种标准里没有的新污染物。技术负责人按"方法验证"流程走了一遍，出了一份验证记录，当作能力证明迎审。

## 关键信号（怎么看出来的）
- 该方法**不在任何现行标准里** → 属非标方法
- 准则要求：标准方法做"验证"（确认本实验室能正确操作），**非标方法必须做"确认"**（检出限 / 精密度 / 准确度 / 偏差全部确认 + 偏离审批）
- 评审专家翻开记录，第一句："这是确认还是验证？"——发现只有验证，没有确认

## 我的判断
**验证 ≠ 确认**，这是评审高频坑。非标方法少了完整的确认记录 + 技术负责人审批，就是硬性不符合项，轻则整改、重则撤项。

## 动作
1. 补做方法确认（检出限 / 精密度 / 准确度 / 偏差四件套）
2. 出确认报告 + 技术负责人签字审批，留偏离说明
3. 修订 SOP：明确"标准方法→验证 / 非标方法→确认"两条线，配判断卡
4. 进 CMA 核查表：单列"方法验证与确认区分"红线条

## 收获（一条可复用原则）
**拿到一个方法，先问"它在标准里吗"。在→验证；不在→确认。** 这条线画错，评审一查一个准。

## 沉淀（进哪个库 / 可写什么 / 喂哪条产品线）
- 进「合规红线」案例库
- 可写公众号：《验证和确认就差一个字，评审能开出不符合项》
- 喂 **CMA 核查表**：方法验证 / 确认区分条（直连 28 条里的对应项）
