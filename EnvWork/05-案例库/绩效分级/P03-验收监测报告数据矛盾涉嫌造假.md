# P03 · 验收 / 监测报告数据矛盾，涉嫌造假

- 问题类型：手工监测报告类 + 在线监测类（高 stakes 红线）
- 覆盖行业：有机化工 / 焦化 / 制药 / 任何有验收 + 监测环节的企业
- 难度：★★★
- 来源：安阳绩效分级项目（脱敏，多家企业核查报告归并）

## 信号清单（怎么一眼看出）
- **验收报告设计风量 vs 监测报告实测风量差一个数量级**：设计 3 万 m³/h，监测 3000–4000（不足 15%）；设计 1.5 万，验收写 3700（不足 30%）但生产负荷写 75%。
- **进口浓度缺失却算出去除效率**：报告未测治理设施进口浓度，无法说明去除率。
- **同一排放口多份报告流量打架**：一份 17–22 Nm³/h，另一份 0 Nm³/h（报告无效）。
- **A 级企业**验收里有某因子、监测报告却"未检出"→ 疑似造假；手工检测进口采样口不符合规范。
- 验收报告与现行监测报告风量 / 浓度对不上，验收报告是否有效待核实。

## 判据锚点（量化红线）
- 验收风量 vs 监测风量**量级一致性**：差 > 3 倍即存疑，差一个数量级即重大疑点。
- **进口浓度是否实测**：缺进口 = 去除效率不可信 = 报告无效。
- **生产负荷与风量匹配**：负荷写 75% 但风量不足设计 30% = 逻辑矛盾。
- **多报告数据一致性**：同一口不同报告数值打架 = 至少一份无效。

## 整改路径
1. 要求企业**重测 / 补充进口浓度**，核实现场真实生产负荷。
2. 核对验收与监测的采样时间、工况是否同期。
3. 确认造假嫌疑 → 按「涉嫌监测报告造假 / 在线数据造假」走**重大不符合**上报，不自行"补救"。
4. 验收报告无效 → 退回重做，不作为绩效评级依据。

## 评审口径（为什么卡绩效等级）
验收 / 监测报告**无效或涉嫌造假** → 一票否决级红线（核查模板明确列「涉嫌在线监测数据造假 / 偷排」）。不仅卡等级，还触发合规风险。

## 行业分布
有机化工、焦化、制药等工艺复杂、验收 + 监测环节多的企业最高发；但任何企业都可能踩。

## 易混淆
- 与 **P01 风量虚标** 区别：P01 是"治理能力真不足"，P03 是"数据本身矛盾 / 疑似伪造"——后者性质更严重。
- 与 **手工监测报告类（维度④）** 重叠，但本模式特指"量级矛盾 / 造假嫌疑"高 stakes 情形。

## 沉淀
- 进产品线：**CMA / CNAS 核查表** → 加一条「验收 vs 监测 风量一致性」红线。
- 可写：公众号《一份验收报告，风量差了十倍，我把它退了回去》。
- 喂象限①：这是"判断 + 信用"双高的事——敢退疑似造假报告，就是你的壁垒。
