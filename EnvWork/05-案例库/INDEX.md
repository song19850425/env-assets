# 环境实验 案例库 · 一线实战复盘

> **作用**：把"会出错、能复盘、下次 10 分钟调出来"的真实案例沉淀下来。
> 这是个人护城河（四象限①核心格「判断力 / 案例库 / 信用圈」）的原料，也是公众号、课程、专家身份的素材源。
> **录入原则**：脱敏（不曝真名 / 单位全称 / 具体城市）、保真实量级、用 SKY 结构（信号 Signal → 判断 Judgment → 动作 / 收获、沉淀）。

## 分类维度（标签体系）
- **域**：采样 / 仪器分析 / 数据异常 / 合规红线 / 咨询判断 / 评审 / 管理
- **红线类型**：采样体积 / 固定剂 / 方法验证确认 / 人员监督能力确认 / 可追溯 / 表述误导
- **难度**：★ ~ ★★★
- **可外化**：是否喂 环境实验 某条产品线（填表向导 / 培训系统 / 一码到底 / CMA 核查表）

## 录入模板（复制即用）

```
## 动作
## 收获（一条可复用的原则）
## 沉淀（进哪个库 / 可写什么 / 喂哪条产品线）
```

## 安阳绩效分级专项（子库）
> 路径：`安阳绩效分级/`。来自郑州大学团队安阳绩效提升项目（76 家培育 + 375 家帮扶 + 813 份日核查报告）。
> 该专项用**扩展红线体系**：核查模板 6 大类（排污许可证 / 污染治理设施 / 无组织排放 / 手工监测 / 在线监测 / 环境管理规范）× 行业 × 判据，详见 `安阳绩效分级/00-三维标签与模式库骨架.md`。

| 编号 | 模式名 | 问题类型 | 状态 |
|---|---|---|---|
| P01 | VOCs 治理「风量虚标 + 活性炭用量不足」 | 污染治理设施 | 样例✅ |
| P02 | 无组织收集效率低（集气罩 / 密闭 / 短流） | 无组织排放 | 样例✅ |
| P03 | 验收 / 监测报告数据矛盾，涉嫌造假 | 手工监测 / 在线监测 | 样例✅ |
| P04 | 排污许可 / 环评 / 监测 执行标准打架 | 排污许可证 | 骨架 |
| P05 | 环保管理能力缺失（DCS / 门禁 / 台账 / 人员） | 环境管理规范 | 骨架 |
| P06 | 废水处理 / 污水池未加盖，废气无组织 | 无组织排放 | 骨架 |

> 安阳专项建议用「模式（Pattern）」结构（信号清单 / 判据锚点 / 整改路径 / 评审口径 / 行业分布 / 易混淆），比根库 SKY 更适合核查类复盘。

### 可调用交付物

> **严格脱敏**：全部样例已隐去企业真名、国家统一宗地代码（410 开头 13 位）、具体地市/区县，仅保留行业典型因子与真实量级，可直接作对外素材。
