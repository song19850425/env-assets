01 · 开篇引入
数据不会自己撒谎，是有人在替它撒谎
某钢铁企业排口的在线数据"稳得可疑"——连续几个月曲线漂亮地贴在限值之下，甚至低到几乎没有波动；可厂区下风向总有股说不清的味道。执法人员夜里突击进站房，开门第一眼就看见：采样管线旁边多了一根不该存在的旁路管，管上装着一个三通阀。
本实训让你站在执法方的位置：先看清烟气数据是怎么"走"出来的、哪些位置能动手脚，再按标准链路突击检查、识别并手工拆除伪装的旁路三通阀、让采样管线复位，最后用执法方自带的标准气体做质控盲测，把"怀疑"变成"证据链"。
CEMS（Continuous Emission Monitoring System，烟气排放连续监测系统）把烟气浓度变成平台上的一条条读数——而这条采样链路上每一段都可能被动手脚。本页所有企业、地点、参数均为脱敏教学设定。
⚠️ 红线声明：本页是教学演示与执法流程实训，所有企业、地点、数据为脱敏设定。不承诺任何执法结论必然成立，也不替代正式的现场检查、采样与司法鉴定程序。
02 · 科学原理
三个问题，决定你做的是不是真的能取证
把下面的三个问题想清楚，交互台里每一条红线你都能提前说出它会怎么拦你。
问题一：数据是怎么"走"出来的？
采样探头烟道内直接抽取
→
伴热采样管线防冷凝、保真传输
→
预处理除水 / 除尘 / 除湿
→
气体分析仪定量测定
→
DAS（Data Acquisition System，数据采集传输仪）上传平台
每一个箭头处，都是可以动手脚的位置：旁路稀释、标气作弊、参数篡改、采样系统失真，分别发生在管线、预处理/分析仪、仪表参数与探头环节。
问题二：什么让"合格数据"变成"造假数据"？
🔀
① 稀释 / 旁路
三通阀把部分烟气放空，掺入空气或低浓度气，实测值被人为拉低——最典型的"物理伪装"。
链路：管线 / 探头
🧪
② 标气作弊
用无证或低浓度标气（标准物质，浓度须可溯源）校准，把整条曲线整体压低；证书缺失或标签被撕是常见破绽。
链路：预处理 / 分析仪
🎚️
③ 参数篡改
改斜率、截距、量程，或设置"输出下限"把低值截断为 0；备案值（斜率 1.000、截距 0）被改即报警。
链路：分析仪参数
💨
④ 采样系统失真
探头堵塞 / 短路、伴热温度不足导致冷凝吸收、气密性破坏——系统本身"失真"，并非真实达标。
链路：探头 / 管线
问题三：靠什么把"怀疑"变成"证据链"？
🔧
物理痕迹
多出的阀门 / 管路、被撕的钢瓶标签——一次性、不可逆，必须最先固定。
物证
🕒
时间线
数据异常起止点与阀门安装 / 参数改动时间吻合，互相印证。
时序
🧾
后台日志
DAS / 仪表操作日志与参数修改记录，能还原"谁、何时、改了什么"。
数据
🎯
比对与盲测
手工比对监测 + 执法方自带标准气体的盲测结果，把怀疑坐实为结论。
结论
把三条连起来看：先取证（物理痕迹），后动手（拆阀 / 复位）——物理痕迹一旦破坏就不可恢复。时间线、后台日志、盲测，是让证据彼此印证的"三脚架"。
03 · 操作规程
八步走完，顺序就是证据链
执法检查（CEMS）的标准链路如下，顺序错了，证据可能不被采信——交互台里会直接拦你。
顺序红线：先动手拆阀 = 现场原始状态灭失（物证没了）；不复核气密性就出笔录 / 做盲测 = 数据仍不可信。每一步都必须在上一步完成之后。

关卡说明：四关顺序解锁。完成上一关才能进入下一关；关卡 1–3 未过关时，关卡 4（盲测）不响应并提示。关卡 2 顺序错会被拦截并解释原因。
关卡 1 · 站房勘察（点选 4 处异常）
点击你认为异常的勘察点。共 4 处异常，找全即过关；点错正常项会扣分。日志区逐条记录你的判断。
关卡 2 · 拆除伪装与管线复位（按正确顺序）
把下方八步按"执法检查标准链路"的正确顺序依次点击。顺序错会被立即拦截并给出原因。全部排对即过关（自动关闭旁路阀、拆除伪装三通阀、恢复伴热）。
关卡 3 · 参数与备案一致性核对
勾选你判断为被篡改的项（现场值 vs 备案 / 验收值）。量程记作 FS（Full Scale，满量程）。判对全部 4 项篡改、且不误勾正常项即过关。
关卡 4 · 标准气体盲测（质控盲测）
执法方自带标准气体（不透题）：企业事先不知道标气浓度。SO₂ 浓度 C_std = 200 μmol/mol，证书编号 CEMS-STD-2025-200（教学示例编号）。通入后读取 CEMS 示值，自动计算示值误差、响应时间与 24h 漂移，并按 HJ 76-2017 技术指标判定。
📐 判定档（HJ 76-2017 技术指标）
· 示值误差：满量程较大（SO₂ 量程 ≥100 μmol/mol）时 ≤ ±5%（相对标准气体标称值）；量程较小档 ≤ ±2.5% FS。本页 SO₂ 量程 500 μmol/mol，按 ±5%（相对 C_std 标称值）档判定。
· 响应时间：系统（含采样管线）响应时间 ≤ 200 s（HJ 76-2017 §6.2.1.2，现场检测口径，本关按此判）；分析仪仪表响应时间（上升+下降）≤ 120 s（§6.1.1.1，实验室/型式检验口径，本关不引用）。
· 24h 漂移三档：分析仪 ≤ ±2% FS；CEMS（气态污染物）≤ ±2.5% FS；颗粒物 CEMS ≤ ±2% FS。本页按 ±2.5% FS（气态污染物 CEMS 档）判定；另一档为 ±2% FS（分析仪 / 颗粒物）。
⚠ 模型边界与判定口径说明
· 本关标准气体从采样探头处通入，检验含采样管线的全系统响应特性，故按 §6.2.1.2 系统响应时间 ≤200 s 判定（分析仪仪表 ≤120 s 属实验室口径，本关不引用）。
· 真实执法亦应在采样探头处通入标准气体做全系统测试（含采样管线、预处理），此时不拆除旁路、不改动采样系统属正常程序，不构成造假；本页为教学简化，将"拆旁路"前置到解锁环节，请勿与真实全系统标气测试混淆。
05 · 总结与黄金法则
四条黄金法则，考场和现场都会考
1️⃣
先取证，后动手
物理痕迹是一次性、不可逆的证据——多出的阀门 / 管路、被撕的钢瓶标签，拆了就没了。
顺序红线
2️⃣
多出的阀门 = 直接物证
旁路管、三通阀、稀释装置不是"设备故障"，而是故意造假的直接物证，优先固定。
物证红线
3️⃣
盲测要用自带标气、不透题
这是把"怀疑"变"结论"的那一步：用执法方自己的标准气体，避免企业预先调低量程 / 斜率应对检查。
结论红线
4️⃣
造假不只是行政责任
篡改自动监测数据涉嫌犯罪的，依法移送司法机关（见法释〔2023〕7号），可能承担刑事责任。
责任红线
这个实训真正要练的能力：面对一间站房，能先固定物理痕迹（关卡 1），再按证据链顺序拆除伪装、复位管线（关卡 2），把现场值与备案值逐一对账识破参数篡改（关卡 3），最后用自带标准气体盲测把"疑似不合格"坐实为"不符合 HJ 76 技术要求"（关卡 4）。缺任何一环，结论都站不住。
