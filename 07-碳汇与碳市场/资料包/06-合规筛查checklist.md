# 合规筛查 Checklist（地块级）

> 用途：动作 11。逐块地打勾，任何一项"否/不确定"即排除或暂缓，留书面记录。红线：权属与生态红线是两大死穴。

## 一、土地类型符合
- [ ] 造林项目：规划造林地 / 宜林地 / 疏林地 / 灌木林地 / 未成林造林地
- [ ] 森林经营项目：人工乔木林地（中幼林）
- [ ] 非湿地、非农田、非城镇建设用地

## 二、起始时间符合
- [ ] 造林项目：2005-02-16 之后营造林
- [ ] 森林经营项目：2005-02-16 之后的中幼林
- [ ] 有营造林台账 / 作业设计佐证（林权证、验收证）

## 三、不在禁止区域
- [ ] 不在生态保护红线**核心区**
- [ ] 不在自然保护地**核心区**
- [ ] 非饮用水水源一级保护区（视方法学）

## 四、权属清晰（死穴之一）
- [ ] 集体林：村民/村集体**书面同意**（附录 F 要求）
- [ ] 国有人工林：经营单位**授权书**
- [ ] 无权属争议

## 五、无重复开发（死穴之二）
- [ ] 未纳入退耕还林重复申报
- [ ] 未在其他碳信用机制（VCS/GS 等）开发
- [ ] 同一地块仅开发一个项目

## 六、非排除地类
- [ ] 非湿地
- [ ] 非耕地 / 永久基本农田
- [ ] 非违法占地

## 七、可监测性
- [ ] 边界可矢量化（有影像/林权证范围）
- [ ] 可设样地或遥感覆盖验证
- [ ] 非碎片化到无法计量

---

## 判定规则
- 全部 ✅ → **合格，进入设计文件**
- 任一项 ❌ → **排除，记录原因**
- 任一项 ⚠️ 不确定 → **暂缓，补证后再判**

## 输出
- 填 `11-合规筛查结果表模板.csv`，每块地一行 + 综合判定 + 备注。
- 排除地块必须写清原因（后期审定追溯用）。
