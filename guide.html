全部 106 件都是公开的，但一次发全部等于没发 —— 没人会自己从 106 件里挑。

所以按机构类型各挑了 10 件，按优先级排好。你是哪一类，点上面那个标签。

怎么用：选一个标签 → 从头往下点 → 哪件点开不知道干嘛，记下来告诉我。 我要的正是这个 —— 哪几件是真有用的，哪几件是我自己以为有用。

适合谁：20~80 人、有独立质量室、有 LIMS。已经在为软件花钱，最可能是客户。

  1. CMA 现场核查总表（2023 版）
    评审前自查对着过一遍，缺什么补什么
  2. CNAS-CL01 现场核查总表
    走 CNAS 认可的话，用这份
  3. CMA 与 CNAS 双体系对照表
    两套体系条款对应关系，不用来回翻
  4. 角色化核查清单
    按岗位分：技术负责人查什么、质量负责人查什么
  5. 质量控制训练室
    四关判读训练：平行样 / 空白 / 校准 / 异常处置，判据逐条带标准出处
  6. EnvStandard 标准库
    24 份标准结构化入库，333 项检测因子、466 项规定参数，逐条可溯源
  7. 监测方案智能生成器
    按土壤 / 地下水 / 废水 / 废气 / 噪声场景出方案
  8. 第三方检测机构合规管理 · 操作规范
    机构自身合规的作业规范样板
  9. 水质评价标准速查表
    写报告时对着查，不用翻标准原文
  10. 检测因子实验室交互方案
    一批样品从接样到出报告的完整流程设计

适合谁：20 人以下、体系在建或刚拿证。最缺培训，痛点最痛。

  1. 仪器操作培训（6 台，逐步走查）
    AAS / 紫外 / 天平 / 培养箱 / 生物安全柜 / 大气采样器，新人可以自己先点一遍
  2. COD 检测实验 · 从水样到报告
    一条完整的链路：从拿到水样到出报告，最适合新人建立整体感
  3. 水质四项（COD / 氨氮 / 总磷 / 总氮）
    四项常规指标一次走完
  4. 土壤采样布点
    布点方案怎么定，拖一拖就看出来
  5. 地表水采样布点
    断面怎么选、点位怎么排
  6. 固定源废气采样
    废气采样最容易在细节上出错
  7. 水和废水采样填表向导
    原始记录表怎么填，一步步来
  8. 土壤地下水初步调查 · 操作规范
    拿到一个土壤调查项目，从哪开始
  9. 质量控制训练室
    质控不是补流程，是报告能不能签字的判据
  10. CMA 现场核查总表（2023 版）
    即使还没到评审，先看看将来要过哪些关

适合谁：环境专业实训课、机构内训。决策快，适合做案例。

  1. 78 个交互实验（按主题筛选）
    首页按「交互式实验」筛，采样布点 / 检测实验 / 仪器分析 / 环境评价 / 修复 / 大气 / 执法
  2. 环境质量综合体检中心
    把水气土声几个维度合起来评价，适合做课程大作业
  3. 「读懂」系列 7 件
    读懂一个厂 / 一条河 / 一个湖 / 一场雨 / 一块地 / 一片天，一节一个主题
  4. 仪器操作培训（6 台）
    实训课前先让学生自己点一遍，课上省一半时间
  5. 检测实验（12 个完整流程）
    从 COD 到 ICP-MS、GC-MS，都有可操作页面
  6. 质量控制训练室
    四关判读训练，自带计分 —— 可以直接当课后作业
  7. EnvStandard 标准库
    让学生自己查标准、对条款，比背讲义有用
  8. 案例库（11 个真实脱敏案例）
    每个案例都是真实踩过的坑，带量化红线
  9. 实验分组任务单（可下发各实验组）
    一次实验怎么分组、各组做什么，直接打印下发
  10. 项目大纲（这个库按什么组织）
    按第三方检测实验室的主体构架组织的 11 个环节
