原理
它在测什么，怎么测
DHP-9052 和 BPX-272 同属电热恒温培养箱，给微生物恒定温度孵育。红线更强调外壳有效接地、物品不挤留空间、周围无易燃易爆物——因为它用电热丝加热，接地和防火是安全底线。流程是 电源拨1 → SET 设温 → 升温恒温 → 放物关内外门。
🔌
电源拨 1 + 接地
电源开关拨到 1 位，且外壳必须有效接地。不接地 → 漏电风险，危及人身。
接地红线
🌡️
SET 设温度
按 SET 设到目标温度（如 37.0℃）。设错 → 该长的菌不长。
设定红线
📦
物品不挤留空间
培养物之间留空间，保证箱内空气对流温度均匀。
放置红线
🔥
周围无易燃易爆
仪器周围不得放易燃易爆物品。电热丝高温，遇易燃物有火灾隐患。
防火红线
下面这个操作台，完全依据一份真实受控作业指导书搭建。你可以随便点——没接地就开机、温度设错、塞太满、周围有易燃物，系统都会直接提醒你。

操作规程关键点

对照真实受控操作规程，下面是从操作规程里直接提炼的"红线"。上面模拟台每一条都做了校验：
🔌
外壳必须有效接地
电源拨 1 前确认外壳接地。不接地 → 漏电危及人身，是安全红线。
接地红线
📦
物品不挤留空间
培养物之间留空隙保证对流。塞太满 → 温度不均。
放置红线
🔥
周围无易燃易爆
仪器周边不得放易燃易爆物。电热丝高温有火灾隐患。
防火红线
🚪
关好内外门
放物后关好内外门保温。门没关 → 温度达不到、能耗高、结果差。
