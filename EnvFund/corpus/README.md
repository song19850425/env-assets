# 语料库说明

规则池的扩展**必须由真实指南驱动**，不能凭常识臆造词表 ——
否则只是把幻觉从模型搬进规则文件。

## 目录约定

```
corpus/
├── central/        中央级指南（生态环境部、财政部发文）
├── provincial/     省级指南（各省生态环境厅、财政厅发文）
└── README.md
```

## 入库要求

| 项 | 要求 |
| --- | --- |
| 格式 | `.txt` 或 `.md`（PDF 请先转文本，可用 `app/parser` 或 OCR 工具） |
| 编码 | UTF-8 |
| 完整性 | **保留完整章节结构**，尤其是「不纳入支持范围」「负面清单」章节 |
| 命名 | `<年份>-<发文单位>-<指南名称>.txt`，如 `2025-生态环境部-水污染防治资金项目储备库入库指南.txt` |

**负面清单章节绝对不能省。** 它是排除规则的唯一依据来源，
省了就没法回归排除规则、也没法验证负面清单提取的完整性。

## 采集范围建议

优先收这些（覆盖规则池的主要盲区）：

1. **中央级**
   - 水污染防治资金项目储备库入库指南
   - 大气污染防治资金项目储备库入库指南
   - 土壤污染防治资金项目储备库入库指南
   - 农村环境整治资金项目储备库入库指南
   - 重点生态保护修复治理资金（山水工程）申报指南
   - 应对气候变化及减污降碳协同相关通知

2. **省级**（挑 3-5 个省，覆盖不同区域特征）
   - 各省生态环境专项资金申报指南
   - 各省农村生活污水治理专项
   - 各省矿山生态修复专项
   - 有独立赛道的省（碳达峰、监测能力建设、EOD）

目标：**20-30 份**。低于 10 份统计意义不足。

## 跑回归

```bash
# 全库覆盖分析 + 漏报排行
python tools/rule_coverage.py corpus/ --json data/coverage_report.json

# 单份详细（看某份指南哪些词没被覆盖）
python tools/rule_coverage.py corpus/provincial/xxx.txt -v
```

## 怎么读结果

`rule_coverage.py` 输出分两块，**要区别对待**：

### 第一块：领域锚点漏报 → 该补规则

出现在「未被任何规则覆盖」里，且属于**领域特征词**的（如"湖库""石漠化""生物多样性"）：

→ 加进 `data/jev_rules.json` 对应标签的 `any` 列表。

### 第二块：机制词/通用词 → **不该补规则**

如"补助""绩效""考核""以奖代补""中央""省级"：

→ 这些是**资金机制词**，全部指南都有，进了领域规则会让规则失去区分度。
（"补助"进了 WATER 规则，那所有指南都会命中 WATER）

→ 它们属于**字段抽取**范畴，由 LLM 抽进 `funding_rules` / `performance_targets` 字段。

## 补规则的判断标准

一条候选锚点词该不该进规则，问三个问题：

1. **它是领域特征词还是通用词？** 通用词不进（见上）。
2. **它能区分赛道吗？** "治理"这种词所有赛道都有，没区分度，不进。
3. **它会不会误杀？** 加进 `any` 前想清楚：新词会不会让不该命中的文档命中？
   必要时配合 `none` 保护词使用。

## 回归纪律

每次改完规则库，**必须**：

```bash
python tests/test_engine.py            # 62 项既有行为不能破
python tools/rule_coverage.py corpus/  # 漏报数应下降，且无新增误判
```

两个都过了才算改完。**只改 JSON 不跑回归，等于没改。**
