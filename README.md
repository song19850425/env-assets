# 环境检测 · 数字资产库

> 一个干了十几年环境检测与环保咨询的人，把日常工作里**真的用得上的东西**做成了能点开就用的网页。
> 不是 PPT，不是概念稿 —— 每件都能在浏览器里直接操作。

---

## 这是什么

这里是长期积累的环境检测 / 环保咨询方向的**数字化工具与教学资产**合集。

做这些的起点很简单：实验室和现场里那些"看一眼就懂、但说不清"的东西（滴定终点、空白漂移、
穿透曲线、风量虚标），写在纸上永远是死的。做成能拖、能点、能看实时反馈的网页，
新人上手时间能砍掉一大半。

所以这个库分两类东西：

| 类型 | 干什么用 | 谁来用 |
|---|---|---|
| **交互式实验 / 仪器培训** | 在浏览器里练操作、看现象、出结果 | 检测机构新人、高校课程、培训机构 |
| **操作规程 / 工具 / 案例库** | 干活时对着抄、对着填、对着查 | 同行、企业环保负责人、咨询顾问 |

## 怎么用

**只想看看** → 在仓库里点开任意 `.html` 文件。

**想拿去上课** → 整个文件夹拷给老师/学员，断网也能跑，无需安装任何环境。

**想自己改** → 全是单文件 HTML，没有构建步骤、没有外部依赖，记事本打开就能改。

---

## 关于数据

- 库内所有案例、企业名称、人员信息、地名**均已脱敏处理**。
- 所有标准条文引用均标注出处，实际使用请以国家/地方发布的**现行有效版本**为准。
- 本库内容**不构成法定检测报告**，不替代具备资质的第三方检测机构出具的结果。
