## 这是什么

这里是长期积累的环境检测 / 环保咨询方向的**数字化工具与教学资产**合集。

做这些的起点很简单：实验室和现场里那些"看一眼就懂、但说不清"的东西（滴定终点、空白漂移、
穿透曲线、风量虚标），写在纸上永远是死的。做成能拖、能点、能看实时反馈的网页，
新人上手时间能砍掉一大半。

按「你要干什么」分，库里放三类东西：

| 你要干什么 | 产品线 | 里面是什么 |
|---|---|---|
| 我要学会怎么做 | **EnvLab** | 78 件交互式实验 + 6 台仪器操作培训 + 质量控制训练室，在浏览器里走一遍完整流程 |
| 我要把活干完 | **EnvWork** | 12 件工具速查 + 4 份作业规范 + 3 个脱敏案例 + 2 件碳市场 |
| 我要查标准 | **EnvStandard** | 24 份标准的结构化索引：333 项检测因子、466 项规定参数，逐条带出处；并含规则终审引擎 |
| 我要看数据 | **EnvData** | 豫北四市空气质量日报 / 周报 / 月报，流水线每小时自动生成 |
| 我要报资金 | **EnvFund** | 环保资金申报指南识别 Agent：LLM 抽取 + 硬规则终审，每个判定带原文证据链（Python 工程，非网页资产） |

合计 **106 件**可交互资产（EnvData 是自动流水线产物、EnvFund 是 Python 工程，均不并进件数）。

## 维护约定（给改这个仓库的人）

- **改资产数要同时改两处**：`index.html` 里的 `SECS` 数组（唯一口径源）和页脚的总数。
  `build_about.py` 会拿首页口径与磁盘实际文件数对拍，不一致就拒绝生成 —— 这样数字漂不了。
- **EnvStandard 的页面是生成的**：改数据或模板后跑 `python EnvStandard/build_envstandard.py`，
  它会校验标准 ID、资产路径、关系引用和 HTTPS 来源。不要手改 `EnvStandard/index.html`。
- **guide.html 也是生成的**：跑 `python build_guide.py`。它把「三类机构各该先看哪 10 件」
  写成数据，**生成时逐条校验资产路径存在** —— 资产改名/移动会让生成器直接报错，
  不会让发给客户的清单里出现死链。
- **about.html 也是生成的**：跑 `python build_about.py`。大纲里每个环节引用的路径都会校验存在性。
- **质控训练室也是生成的**：跑 `python build_qc_trainer.py`。它的判据（平行样相对偏差上限、
  试剂空白吸光度上限、声学校准偏差上限……）**全部从 `EnvStandard/data/standards/*.json` 现读**，
  并断言训练题的判定与判据一致 —— 判据错了会拒绝生成，不会让页面教错。
  **加标回收率限值、相关系数 r 下限等标准未给统一阈值的判据，本模块不编造**，
  在页面末尾单列一节说明。
- **EnvData 的 `scripts/page_v2.py` 与 `daily_report.py` 是从外部项目镜像过来的**，
  改写会让镜像与源文件产生实质差异，请不要为了改样式去动它们；
  导航页模板 `scripts/index_pages.py` 是本仓库的唯一源，可以改。
- **全站禁外部依赖**：不引 CDN、不引外部字体、不引外部脚本，保证断网可用。

## 关于数据

- 库内所有案例、企业名称、人员信息、地名**均已脱敏处理**。
- 所有标准条文引用均标注出处，实际使用请以国家/地方发布的**现行有效版本**为准。
- 大气数据来自中国环境监测总站实时发布平台，由自动化流水线生成、**未经人工审定**。
- 本库内容**不构成法定检测报告**，不替代具备资质的第三方检测机构出具的结果。
