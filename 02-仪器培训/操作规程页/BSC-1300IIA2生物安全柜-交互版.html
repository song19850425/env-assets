原理
它在测什么，怎么测
生物安全柜（BSC）不是培养箱，而是无菌操作 + 生物安全防护的平台：向下层流 + 前窗进风形成气流屏障，既保护样品不被污染，也保护操作人不被病原微生物侵害。红线是一条严格顺序链：操作前 UV 照 30min → 关 UV 开鼓风机 → 拉门到 8 英寸 → 无菌操作 → 拉下门关鼓风机开 UV 30min → 关 UV。
🔵
操作前 UV 30min
操作前先开紫外线灯照 30 分钟灭菌。跳过 → 台面带菌，样品污染、人员暴露。
灭菌红线
🌬️
关 UV 开鼓风机
灭菌后关 UV、开鼓风机建立气流屏障。开着 UV 又做人 → 紫外伤眼伤皮肤。
顺序红线
🚪
拉门到 8 英寸
玻璃门拉到 8 英寸工作高度（警报停）。太高/太低 → 气流屏障破，防护失效。
门高红线
🔁
结束再 UV 30min
操作完拉下门、关鼓风机、开 UV 照 30min 终灭，最后关 UV。漏终灭 → 残留污染。
终灭红线
下面这个操作台，完全依据一份真实受控作业指导书搭建。你可以随便点——没照 UV 就操作、门没到 8 英寸就动手、顺序反了，系统都会直接提醒你。

操作前开 UV 照 30min 灭菌。跳过 → 台面带菌，样品污染、人员暴露风险。
灭菌红线
🚪
门须 8 英寸
玻璃门拉到 8 英寸工作高度（警报停）。太高/太低 → 前窗气流屏障破，防护失效。
门高红线
🔔
警铃响勿操作
警铃响说明门位/气流异常，必须停手排查。强行操作 → 失去防护。
报警红线
🕶️
UV 仅无人时开
紫外线伤眼伤皮肤，只有室内无人才能开 UV。操作中须关 UV、靠鼓风机气流防护。
