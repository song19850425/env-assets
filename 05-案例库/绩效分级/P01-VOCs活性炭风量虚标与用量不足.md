# P01 · VOCs 治理「风量虚标 + 活性炭用量不足」

- 问题类型：污染治理设施类
- 覆盖行业：塑料制品 / 工业涂装 / 包装印刷 / 家具制造 / 制药（涉 VOCs 全域）
- 难度：★★
- 来源：安阳绩效分级项目（脱敏，多家企业核查报告归并）

## 信号清单（怎么一眼看出）
- 风机**标称风量**远大于**检测报告实测风量**：标称 2 万 m³/h，实测 <1 万；标称 1 万 / 套 ×7 套，实测仅 3000–4000。
- **活性炭年用量**远低于环评设计：设计 15.1 t/a，实际外送 100–200 kg/a；箱填充不足、表观发白、更换频次不达标。
- 申报 **A 级**却用 **UV+活性炭、等离子+活性炭** 等单一 / 低效组合工艺（A 级禁用）。
- 多套装置共用一个活性炭箱、危废间设吸附箱却**无排气口**，无法判定效率。

## 判据锚点（量化红线）
- 实测风量 / 设计风量 比值：< 30% 即重大疑点（曾见设计 3 万、监测 3–4 千，不足 15%）。
- 活性炭用量比：实际装填 / 环评设计，差 1–2 个数量级 = 不足。
- 工艺等级：A 级末端治理禁用单一活性炭吸附、UV 光氧 + 活性炭等低效组合（须催化燃烧 / 沸石转轮 + 燃烧等）。

## 整改路径
1. 核实现场**真实风量**（不是铭牌）→ 反推所需活性炭装填量（按风量 × 浓度 × 停留时间算）。
2. 补足活性炭装填量 + 建立**更换台账**（每次称重 / 照片留痕）。
3. 申报 A 级但工艺不符 → 要么升级工艺，要么按实际等级申报，别硬冲 A。
4. 危废间 / 污水池废气必须**有收集 + 有排气口 + 可测效率**。

## 评审口径（为什么卡绩效等级）
风量不足 / 活性炭不足 → 去除效率不达标 → 不满足申报绩效等级，属「污染治理设施安装和运行不符合要求」。A 级企业此类问题直接判不符合。

## 行业分布
涉 VOCs 行业通杀：塑料挤出、工业涂装喷漆 / 喷塑、包装印刷、家具喷涂、制药废气。本项目 375 家帮扶中**出现频率最高**的一类。

## 易混淆
- 与 **P02 无组织收集效率低** 常并发（前端没收集 + 末端量不足），但 P01 是「末端治理量不够」，P02 是「前端没收集」。
- 与 **P03 报告造假** 区别：P01 是"能力真的不足"，P03 是"数据本身矛盾 / 疑似伪造"。

## 沉淀
- 进产品线：**现场核查一页纸 SOP**（B 方案）→「风量 / 活性炭 速查判据」卡片。
- 可写：公众号《申报 A 级前，先数数你家的活性炭够不够》。
- 喂象限①：这类问题见一次就会，是典型的「判断复利」素材。
