# P02 · 无组织收集效率低（集气罩 / 密闭 / 短流）

- 问题类型：无组织排放类
- 覆盖行业：工业涂装 / 塑料制品 / 铸造 / 金属表面处理 / 医疗设备
- 难度：★★
- 来源：安阳绩效分级项目（脱敏，多家企业核查报告归并）

## 信号清单（怎么一眼看出）
- **集气罩设计不合理**：距污染源过远、罩口偏小，23 台挤出机普遍收集效率低。
- **车间门窗打开生产**，未落实密闭；固化 / 喷涂间**风速太小、形不成负压**。
- **气流短流**：送风口与集气口相距 < 0.5 m，废气刚排出就被吹散，收集效果差。
- **危废间 / 污水池 / 泄灰斗**未密闭收集：危废间密封差、污水池未加盖、除尘泄灰斗扬尘。
- 部分打磨 / 焊接 / 木工工序在大车间内散做，无粉尘收集。

## 判据锚点（量化红线）
- 集气罩控制风速：一般 **≥ 0.3 m/s**（逸散点）；罩口距源越近越好。
- 车间**微负压** + 门窗密闭生产；喷涂 / 固化间须保证风速成负压。
- 消除**短流**：送风与集气口应保持足够距离，避免气流直冲。
- 废水池 / 危废间 / 泄灰点必须**密闭 + 收集 + 有排气口**。

## 整改路径
1. 优化集气罩：密闭化、近源、保证控制风速；不能用罩的改整体密闭 + 微负压。
2. 车间门窗管理 + 生产期间密闭；固化 / 喷涂间补风成负压。
3. 废水池、危废间、泄灰点加盖密闭并接入收集系统。
4. 重新布局送排风，消除短流。

## 评审口径（为什么卡绩效等级）
无组织排放管控不到位 → 不满足绩效等级，尤其 **A / B 级对无组织要求严**（物料贮存、转运、生产工艺全环节）。属「无组织排放问题」。

## 行业分布
工业涂装（喷漆 / 喷塑）、塑料挤出、铸造、表面处理、医疗设备机加工。与 P01 并发率极高。

## 易混淆
- 与 **P01 风量虚标** 并发但不同层：P02 = 前端没收集（无组织），P01 = 末端量不足（有组织治理）。
- 与 **P06 废水池未加盖** 相邻：P06 专指水处理设施无组织，P02 更宽泛含生产工艺无组织。

## 沉淀
- 进产品线：**现场核查一页纸 SOP** →「无组织速查：集气罩 / 密闭 / 短流」卡片。
- 可写：公众号《车间门窗开着生产，绩效等级先扣一分》。
- 喂象限①：无组织是"看现场"的硬功夫，见过 50 个车间就有手感。
