# 安阳绩效分级 · 三维标签体系与模式库骨架

> 来源：郑州大学团队「安阳市绩效提升企业培育 / 现场核查」项目（76 家培育清单 + 375 家帮扶台账 + 813 份日核查报告）。
> 定位：把 813 份散报告蒸馏成 **可检索、可调用、可对外** 的「问题模式库」，喂进个人护城河（象限①）。
> 方法：先用核查模板的 6 大类问题作**红线主分类**，叠加「行业 × 红线 × 判据」三维标签，再把个案归并成高频模式。
> 脱敏：样例不曝单位全称 / 具体区县；保留真实量级（风量、活性炭用量、浓度限值）。

---

## 一、三维标签体系

### 维度① 行业（来自培育名单 + 工作量统计 + 4 行业分类目录）
| 大类 | 典型行业 |
|---|---|
| 涉 VOCs | 包装印刷、塑料制品、涂料制造、家具制造、工业涂装、制药 |
| 金属类 | 铸造、金属表面处理及热处理、机械制造 |
| 建材类 | 商砼（沥青）搅拌站、砖瓦窑、水泥 |
| 省级重点 | 长流程钢铁、焦化、有机化工、燃煤 / 涉锅炉通用 |
| 其他 | 纺织印染、造纸、垃圾发电、饲料加工、医疗设备 |

### 维度② 问题类型（= 核查模板 6 大类，作为案例库红线主分类）
1. **排污许可证类** — 管理类别错误 / 设施数量与许可不一致 / 执行标准错误
2. **污染治理设施类** — 安装运行不符 / 风量虚标 / 活性炭不足 / 工艺不符等级
3. **无组织排放类** — 物料贮存 / 转运 / 生产工艺无组织 / 收集效率
4. **手工监测报告类** — 基本信息错误 / 数据质量 / 频次完整性
5. **在线监测类** — 站房 / CEMS 运行 / 涉嫌造假 / 偷排
6. **环境管理规范类** — 制度档案 / 生产台账 / 设施台账 / DCS / 门禁 / 人员

### 维度③ 红线判据（每个问题类型下的「锚点」，用来从报告里捡案例）
- **风量**：设计风量 vs 监测风量 比值（实测 < 设计 30% 即重大疑点）
- **活性炭**：环评设计用量 vs 实际外送 / 装填量（差 1–2 个数量级 = 不足）
- **工艺等级**：A 级禁用 UV+活性炭、等离子+活性炭 等单一 / 低效组合
- **收集效率**：集气罩控制风速（一般 ≥0.3 m/s）、车间微负压、气流短流（<0.5 m）、门窗密闭
- **报告一致性**：验收 vs 监测 风量 / 浓度 量级差、进口浓度缺失、多报告数据打架
- **标准一致性**：排污许可 / 环评 / 监测 执行标准是否统一
- **管理能力**：DCS、门禁（国三及以下管控）、台账、环保人员、档案

## 二、模式库骨架（高频问题模式目录）

> 从 813 份报告归并出的跨行业高频模式。P01–P03 已出脱敏样例，P04–P06 待补。

| 编号 | 模式名 | 问题类型 | 覆盖行业 | 状态 |
|---|---|---|---|---|
| P01 | VOCs 治理「风量虚标 + 活性炭用量不足」 | 污染治理设施 | 塑料 / 涂装 / 印刷 / 家具 / 制药 | 样例✅ |
| P02 | 无组织收集效率低（集气罩 / 密闭 / 短流） | 无组织排放 | 涂装 / 塑料 / 铸造 / 表面处理 / 医疗 | 样例✅ |
| P03 | 验收 / 监测报告数据矛盾，涉嫌造假 | 手工监测 / 在线监测 | 有机化工 / 焦化 / 制药 / 全域 | 样例✅ |
| P04 | 排污许可 / 环评 / 监测 执行标准打架 | 排污许可证 | 全域 | 骨架 |
| P05 | 环保管理能力缺失（DCS / 门禁 / 台账 / 人员） | 环境管理规范 | 涂装 / 医疗 / 全域 | 骨架 |
| P06 | 废水处理 / 污水池未加盖，废气无组织 | 无组织排放 | 化工 / 制药 / 全域 | 骨架 |

### P04–P06 信号速记（待扩成完整样例）
- **P04**：同一企业排污许可证、环评批复、监测报告三者执行浓度 / 限值不一致 → 执行标准无法确定；常见于「拟升级企业历史文件版本多」。
- **P05**：申报 A 级却无 DCS / 无门禁；近两月国三及以下车辆进场无管控；台账缺失、环保人员不具备管理能力、档案不齐。
- **P06**：厌氧池 / 二沉池 / 污水池 / 危废间未密闭收集，污泥露天，废气无组织逸散；常与 P02 并发。
