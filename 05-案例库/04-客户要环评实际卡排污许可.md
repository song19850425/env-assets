# 04 客户要环评，实际卡在排污许可

- 域 / 红线类型 / 难度：咨询判断 / 需求识别 / ★★
- 日期：2026-06 / 脱敏场景：某制造企业来询"做个环评"

## 背景
一家制造企业找上门，开口就是"给我们做个环评"。按常规接单的话，直接排环评、报价、排期。

## 关键信号（怎么看出来的）
- 多问一句"什么时候要用" → 明年 Q2 要投产
- 再问"这次扩产规模" → 产能翻三倍
- 查它的排污许可证 → **剩余总量指标基本用满**，翻三倍根本没余量
- 客户自己没意识到：卡住他的不是环评，是先要把排污许可余量理顺

## 我的判断
客户说的 ≠ 客户要的。他要的不是一份环评报告，是"**扩产前的合规路径梳理**"。先理排污许可 + 总量指标，环评才能顺；反过来先做环评，做完发现没总量，全盘白搭。

## 动作
1. 重排服务顺序：先做排污许可余量核算 + 整改 / 交易建议
2. 环评后置，且明确告诉客户"先过许可这关，环评才立得住"
3. 把"时间 + 规模 + 约束"三问做成接单前置清单

## 收获（一条可复用原则）
**客户说的是症状，不是诊断。** 用"什么时候用 / 规模多大 / 卡在哪"三问穿透，往往能救他一命，也救自己返工。
