# 02 VOCs 采样体积不足，"未检出"是假阴性

- 域 / 红线类型 / 难度：采样 / 合规红线 / 采样体积 / ★★
- 日期：2026-04 / 脱敏场景：某企业无组织废气 + 室内空气 VOCs 采样

## 背景
一批 VOCs 采样按"采样时间"够了，报告里按标况体积填了"未检出"。但复核发现：实际累积采样体积远低于方法要求的最少体积。

## 关键信号（怎么看出来的）
- 采样时间达标，但现场是**微负压环境**，流量计读数虚高——实际抽气体积不足
- LIMS 默认按"采样时长 × 标定流量"算体积，没接流量计**实测累积值**
- 负值 / 未检出的点位，恰好都是负压大、体积缺口最大的点位

## 我的判断
体积不足 → 实际富集量不够 → **方法检出限被放大** → 报"未检出"很可能是**假阴性**。这是合规红线：不能拿"未检出"当安全结论，更不能事后补填体积。

## 动作
1. 该点位判为无效，重新采样（换正压采样或校正流量）
2. 回溯同条件所有点位，凡体积不足的一律重采
3. 改 LIMS：体积取流量计实测累积值，缺实测值则锁死报告
4. 填表向导加"采样体积达标"硬性卡点（不足不准进下一步）

## 收获（一条可复用原则）
**"未检出"是最危险的结果。** 它背后可能是真干净，也可能是体积/时间/富集不够的假阴性。看未检出，先验算它的检出限站不站得住。
