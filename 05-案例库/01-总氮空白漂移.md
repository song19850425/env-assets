# 01 总氮空白漂移，先别骂操作员

- 域 / 红线类型 / 难度：仪器分析 / 数据异常 / 试剂本底 / ★★
- 日期：2026-03 / 脱敏场景：某第三方实验室常规批次总氮（TN）分析

## 背景
一批总氮样品，空白平行样吸光度异常偏高，平行 RSD 超 5%。组长第一反应是"操作员手不干净 / 器皿没冲干净"，要重洗重做。

## 关键信号（怎么看出来的）
- 空白值是**随批次系统性漂移**，不是随机跳动——同一人、同一批器皿、同一台紫外，只有空白飘，样品相对正常
- 查试剂批号：偏高批次用的过硫酸钾是**批号 B**，正常批次是批号 A
- 该批号下加标回收也偏低，不是单纯空白问题，是**氧化剂本底高**
- 操作员当班记录正常，器皿按 SOP 冲了三遍

## 我的判断
不是操作问题，是**过硫酸钾空白本底高**（碱热水解不完全 / 储存吸潮结块）。总氮靠过硫酸钾高温消解，试剂本底直接抬空白、压回收。这是经典坑，骂操作员只会掩盖真因、耽误整批。

## 动作
1. 暂停该批报告，不急着重洗器皿
2. 换批号 A 过硫酸钾，重做空白 + 加标，确认空白回落、回收回正
3. 受影响的样品用新试剂复测，原数据封存留痕
4. 把"过硫酸钾批号"纳入试剂验收必检项（空白 + 回收双控）

## 收获（一条可复用原则）
**空白漂移 ≠ 操作失误。先看"批号 / 试剂 / 时间"三维度，再怀疑人。** 数据异常的第一现场是物料台账，不是操作员的手。

## 沉淀（进哪个库 / 可写什么 / 喂哪条产品线）
- 进「仪器分析 / 数据异常」案例库
- 可写公众号：《总氮空白飘了，先别骂操作员》
- 喂 **培训系统·仪器分析**：总氮模块加"空白漂移三查（批号/试剂/时间）"红线卡点
