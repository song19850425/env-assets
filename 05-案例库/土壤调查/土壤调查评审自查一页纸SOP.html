判据速查卡（写报告 / 迎评审前扫一眼）
S01
石油烃/苯并芘检出即判"生产影响"
  • 石油烃(C10-C40)、苯并[a]芘一旦检出 = 生产活动影响（不依赖浓度）
  • 定性句不能省（即使未超筛选值，结论写"风险可接受"）
  • 重金属（锰/锌等）不适用此口径 → 走 S02
  • 定性后须结合工艺环节说明来源路径
S02
超筛选值但源于高背景值
  • 重金属超标 + 周边同步超标 + 梯度不衰减 = 高背景值
  • 评价须参照区域背景值/对照值，非单看 GB 36600
  • 关键判据：内外浓度梯度（周边已高、企业内无抬升=高背景）
  • 缺高背景值论证 = 报告被退回（红线）
S05
特征污染物识别与因子筛选
  • 土壤 = GB 36600 表1 45 项 + pH + 行业特征项
  • 周边土壤 = GB 15618-2018 8 项 + 行业特征项（保证可比）
  • 地下水 = 与土壤特征污染物对应（土壤有苯系物→地下水必测同组）
  • 样品量：土壤约 24–45 件/地块（按规模取，宁多勿少）

六大类评审自查清单（土壤报告红线主分类）
壹
特征污染物识别类HJ 25.1 · GB 36600/15618 · S05
S05 整改要点：布点前先做产污环节核查（机加工→石油烃、涂装→苯系物、热处理→氰化物/重金属）；土壤/周边/地下水特征因子三表一致，否则内外关联性分析(S03)做不了。
贰
监测方案类HJ 25.2 · HJ 166-2026 · S05
核查口径：样品量宁多勿少——后续分位数统计、占标率排序都依赖样本量；层位过浅会漏掉深层污染信号。
叁
数据分析评价类HJ 25.1/25.3 · S01/S03
S01/S02 判断顺序：先看污染物种类——石油烃/苯并芘走 S01，重金属走 S02（除非有强工艺来源证据）。两者非此即彼，混用必被专家退回。
肆
超标原因论证类GB 36600 · S02
S02 论证路径：调区域对照值/背景值 → 做内外关联性分析(S03) → 引地质成因/成土母岩资料证自然高背景 → 附不确定性说明。缺任一步=报告不完整。
伍
报告规范性类HJ 25.1/682 · S03/S04
专家高频退回项：缺不确定性分析(S04)、缺内外关联章节(S03)、口径不统一(S01)——这三条是省级评审必卡，初稿最常漏。
陆
样品追溯类HJ 166-2026 QA/QC · S06
S06 信号：原始数据无 CMA 章、样品链断点 = 数据不可采信 = 报告科学性被否。与 环境实验 一码到底同源思路，建议项目级直接上。
