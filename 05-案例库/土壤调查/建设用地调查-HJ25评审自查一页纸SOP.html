脱敏工作版 2026 / 07 平板可勾选 · 本地留存 环境实验 案例库
核查口径（建设用地准入型 · 脱敏）
本工具对应 建设用地准入型调查——用于地块收储、流转、变性前判定"这块地能否安全再开发"，与"在产企业及周边详查/监管核查"是两条不同业务线（后者见本库另一份 SOP，勿混用）。 通用评审组织方式：土地使用权人（业主）委托调查机构 → 报告受理 → 组织专家评审 → 出具评审意见 → 指导填报全国建设用地土壤环境管理信息系统 → 按结论纳入或免于纳入建设用地土壤污染风险管控和修复名录。 各地组织对口部门与采购方式略有差异，以属地最新规定为准；以下清单按 HJ 25.1—2019 三阶段 + 评审要点通用口径制作。
判据速查卡（写报告 / 迎评审前扫一眼）
B01
第一阶段三要素必须齐全
  • 资料收集 + 现场踏勘 + 人员访谈三项缺一不可
  • 访谈须 ≥3 人且来源不同（管理 / 环保 / 熟悉情况者）
  • 相邻地块、用地历史变迁须查到
  • 任一要素缺失 = 第一阶段结论不可靠（红线）
B02
是否进入第二阶段须有判定
  • 识别到可能的污染源 / 污染活动 → 必须进第二阶段采样
  • 第一阶段结论须有推导链（识别→判断→结论可追）
  • 识别不充分 → 先补第一阶段，不可直接跳采样
  • 专家必查：结论能否支撑"无污染"
B03
规划用地性质决定筛选值
  • 一类用地（居住 / 学校 / 医疗 / 养老 / 公园等敏感用地）
  • 二类用地（工业 / 仓储 / 物流等）
  • 对应 GB 36600 不同筛选值 / 管制值，不可混用
  • 敏感用地从严、优先保护（红线）
B04
布点采样合规
  • 布点方法适用（专业判断 / 系统随机 / 网格）
  • 对照点设置、分层采样（0–0.5 m 表层）
  • 地下水监测井（建井 / 洗井 / 水位）
  • 样品保存运输按 HJ 166—2026 QA/QC
B05
概念模型 CSM 与结论推导
  • 须建 污染源—暴露途径—受体 概念模型
  • 超筛选值 → 是否需 风险评估（HJ 25.3）
  • 是否需风险管控 / 修复
  • 须含 不确定性分析
B06
报告规范性与系统填报
  • 检测报告 CMA 章 + 原始记录 + 质控 可追溯
  • 纳入 全国建设用地土壤环境管理信息系统
  • 按结论纳入 / 免予纳入风险管控修复名录
  • 专家意见 逐条回复闭环
标准依据速查（现行有效 · 评审口径溯源）
说明：下列均为公开现行国家 / 行业标准，本 SOP 的判据与清单条目均可在其中找到出处。所有标准号均为公开信息，非涉密。HJ 25 系列 2019 版已替代 2014 版，HJ 166—2026 已替代 HJ/T 166—2004。
HJ 25 系列
建设用地土壤污染调查与修复（2019）
  • HJ 25.1—2019 状况调查：原则 / 内容 / 程序 / 三阶段技术要求
  • HJ 25.2—2019 监测：风险管控 / 修复监测规范
  • HJ 25.3—2019 风险评估：健康风险评估要求
  • HJ 25.4—2019 修复：修复方案编制
  • HJ 682—2019 术语：统一术语定义
GB 36600
建设用地风险管控标准（2018）
  • 基本项目 45 项 + 筛选值 + 管制值
  • 一类用地（敏感）筛选值更严
  • 二类用地（工业 / 仓储）筛选值较宽
  • 建设用地调查评估必备依据
HJ 166
土壤环境监测技术规范（2026）
  • HJ 166—2026 于 2026-06-01 实施，替代 HJ/T 166—2004
  • 新增：监测方案编制 / 饮用水源周边布点
  • 新增：点位现场核查 / 有机物检测样品采样
  • 完善 QA/QC，删除土壤质量评价
GB 15618
农用地风险管控标准（2018）
  • 适用于 农用地 土壤风险筛查与分类
  • 基本项目 8 项 + 风险筛选值 / 管制值
  • 周边农用地比对时参照
  • 与建设用地 GB 36600 不混用
全国系统
建设用地土壤环境管理信息系统
  • 调查 / 风险评估 / 管控修复全链条填报
  • 评审通过后由对口部门指导填报
  • 结果对接 风险管控和修复名录 管理
  • 属用地准入闭环关键环节
六大类核查清单（逐条勾选）
壹
第一阶段污染识别充分性关联 B01 · HJ 25.1
评审口径：第一阶段是建设用地调查的"灵魂"。三要素任一缺失，第一阶段结论即不可靠，后续采样再漂亮也救不回。
贰
进入第二阶段判定逻辑关联 B02 · HJ 25.1
评审口径：专家最爱挑的就是"凭什么不采样就下无污染结论"。推导链断一处，整份报告退回。
叁
规划用地性质与筛选值关联 B03 · GB 36600
评审口径：同一组数据，一类二类筛选值不同，结论可能逆转。规划用地性质写错 = 整份评价基础错。
肆
第二阶段布点采样合规关联 B04 · HJ 25.2 · HJ 166-2026
评审口径：采样是数据正义的起点。对照点缺失、分层不对、样品超时效，数据直接废。
伍
概念模型与结论推导关联 B05 · HJ 25.1 / 25.3
评审口径：CSM 是连接"数据"和"能不能安全用"的桥。没有 CSM，超筛选值也只是数字。
陆
报告规范性与系统填报关联 B06 · HJ 25.1 / 682 + 全国系统
评审口径：系统填报和名录是准入闭环的最后一环。报告过了但没进系统，地块仍不能动。
