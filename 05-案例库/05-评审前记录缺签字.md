# 05 评审前 3 天发现记录缺签字，别倒签

- 域 / 红线类型 / 难度：评审 / 合规红线 / 人员监督能力确认 / ★★★
- 日期：2026-07 / 脱敏场景：CMA 现场评审前 3 天自查

## 背景
CMA 现场评审前做最后自查，发现一批原始记录：部分缺监督人签字，个别检测人员无对应的"能力确认"记录。

## 关键信号（怎么看出来的）
- 评审专家必查"**人员监督 + 能力确认双线**"——缺任意一项即不符合
- 倒签（补填过去日期）在评审里 = 记录造假，比"缺"更严重
- 当时确实有培训、有在岗，只是**纸质留痕漏了**

## 我的判断
不能补签过去日期（倒签 = 造假，一票否决）。正确做法是走**纠正措施（CAPA）**：说明当时为何漏、现在怎么补确认，绝不做假日期。

## 动作
1. 梳理缺项清单（缺监督签字 / 缺能力确认，分开列）
2. 出纠正措施报告（CAPA）：原因分析 + 纠正 + 预防
3. 补能力确认：附当时培训签到 + 考核记录，确认"当时具备能力"，日期写**补确认当天**
4. 修订记录模板：监督签字 + 能力确认设必填卡点，防再漏
5. 进 CMA 核查表：把"双线"做成评审前自查硬清单

## 收获（一条可复用原则）
**评审前自查用"双线"清单（监督 + 能力确认）。缺项走 CAPA 不倒签——假日期比缺项更致命。**
