看天管控：县级大气分级对策方案

核心思想一句话：风决定大势，人决定名次。县级管控不与天气对抗，而是按气象过程分型、按扩散条件分级，把有限的管控力量集中到边际收益最高的静稳窗口与临界天上；其余时间轻管维持合规底线。本方案给出完整工作流、自动化与人工分工、周版对策的出版节奏，以及可执行性与有效性的诚实评估口径。
三问三答（结论先行）

① 每周一版详细对策可行吗？可行——但须采用“周计划 + 日订正”两级节奏：周版定一周的过程日历与分级安排，日订正只发一行触发消息修正偏差。纯周版不订正，遇预报误差必失灵。② 可执行吗？有条件可执行——关键在触发标准事先由县里签认（预授权）、每镇每日动作不超过 3 条、联动预警期间服从市级统一调度。③ 有效吗？对“过程峰值、临界天保良、相对排名”有效且可验证；对“年均浓度包降多少”不承诺——那主要由气象年景与区域趋势决定，本方案用去气象化评估把“天的功劳”和“人的功劳”分开算账。

一、方法框架（四层）

1 · 过程分型

按未来 72 小时形势分四型：静稳积累型（主战场）、区域传输型（不添乱 + 备说明）、大风扬尘型（只管尘源）、扩散良好型（轻管躺平）。夏季另设臭氧版分型（高温强光型等），与秋冬版分开运行。

2 · 气象分级

按预报风速、边界层高度、通风量与湿度定三档：轻管（合规底线）→ 升档布防（静稳前 48h）→ 满档（静稳中）。升档提前、降档滞后，防反复横跳。

3 · 乡镇分型

用各乡镇站历史数据按风向分组算“指纹”：传输敏感型 / 局地源主导型 / 扬尘型 / 背景型。指纹分冬夏两版（盛行风反转）。县级过程类型 × 乡镇指纹 = 每镇当日动作。

4 · 考核校正

乡镇月度考核做气象/传输校正：传输过程中的区域性超标不简单记在乡镇头上，采用绝对值 + 改善率双轨计分，保住奖惩的服人程度与制度信用。

二、自动化 / 人工分工总表

原则：机器管数据和提醒，人管判断和执行。全流程自动化率约 70%（按工时计），但最关键的升档拍板与现场执行永远保留人工——这既是科学边界（预报是概率不是确定值），也是责任边界（管控措施扰动生产生活，须有人担责）。

三、周版对策方案：可行性与出版规范

为什么“周”是合适的节奏

  • 大尺度形势 3–5 天可预报、7 天可看趋势，周版恰好卡在可预报窗口的上限：再短（日版）人力跟不上，再长（月版）形势全变。
  • 县乡工作本就以周为调度单位（周例会、周排班），周版能直接进现成的工作节奏，不另造流程。
  • 成本账：成稿 80% 自动化后，人工只需复核研判约 1–2 小时/县/周。一名专家 + 一条管线可同时支撑多县——这是本模式区别于“一县驻一个团队”的成本根基。

周版固定结构（八节，缺一不发）

章节内容要点方式
1. 上周复盘预报命中率、上周过程实际走势、措施落实率、去气象化小结（本节决定本方案的信用）半自动
2. 本周形势总览一周天气形势一句话定性 + 置信度分级（高/中/低）半自动
3. 过程日历逐日过程型（静稳/传输/扬尘/扩散）与预计强度，标注不确定性最大的两天半自动
4. 分日分级表逐日建议档位与升/降档时点；与市级预警的衔接说明（联动期间以市级为准）半自动
5. 乡镇重点名单按指纹点出本过程每类乡镇各盯哪几个、盯什么源；每镇动作 ≤3 条半自动
6. 分源动作清单工业错峰、工地、道路、禁烧、餐饮、重卡六类源在本周各档位下的具体动作，含防抢产/防平移提示人工 定稿
7. 临界天提示预计卡在优良阈值附近的日期与乡镇——本周的胜负手，单独预警全自动
8. 证据与申诉事项上周可申诉剔除事项的证据包进度、本周需留存的证据清单半自动

日订正纪律：周版发布后，每日清晨只发一行订正消息（例：“订正：周四静稳提前至周三晚，升档时间提前 12h，其余不变”）。无变化不发。与晨检卡同一逻辑：异常才推，静默即正常。这条纪律是防“狼来了”的关键——订正发得越克制，升档通知越有人听。

四、可执行性：五个前提与四条设计纪律

前提（缺一则降级运行或不启动）

  • 数据前提：乡镇站逐时数据可获得（接口或定期数据包）。拿不到时只能做县级版（用县站 + 周边市站），乡镇分型章节停用并如实标注——这是全方案唯一的硬门槛。
  • 授权前提：《分级触发表》须经县局事先签认：达到哪档、自动执行哪套动作，不必逐次开会请示。无预授权，48 小时提前量会被请示流程吃光。
  • 执行前提：驻场/乡镇网格有人接单。系统只负责研判与派单，不能替代现场人力；无人执行的县只卖研判版，不承诺落地效果。
  • 服从前提：区域联动预警启动期间，本方案档位自动让位于市级统一调度，方案只做本地细化补充，不另发指令。
  • 民生前提：满档动作避开民生保供行业，动作清单发布前过一遍民生清单——为管控而断供，是最快的翻车方式。

设计纪律

  • 低后悔动作优先：预报准确率约八成，按“后悔成本”排动作顺序——先上洒扫、覆盖检查、巡查加密这类错了也无害的；停工限产类高成本动作等置信度升至高档、或进 48h 窗口后才上。给空报留预算：一个季度允许约 1–2 次升档空报，写进方案明处，不藏着。
  • 每镇每日 ≤3 条动作：乡镇人手薄，清单超过 3 条等于没有清单。
  • 防平移与抢产：错峰避开夜间逆温最强时段；升档通知不提前过量发布高成本措施细节，防企业抢生产把排放堆到过程前夜。
  • 时段对齐污染节律：发力时段为傍晚—夜间（火点、重卡、散烧高发 + 逆温生成），巡查排班按污染时钟排，不按行政班次排。

五、有效性：承诺边界与验证方法

能承诺（可验证）

  • 升档提前量 ≥48h 的过程占比
  • 临界天保良成功率（阈值 ±10μg 内保住优良的次数）
  • 过程峰值相对同类历史过程的削减
  • 措施落实率、申诉剔除成功天数
  • 相对名次：与同市邻县的去气象化差距变化

不能承诺（写进合同免责）

  • 年均 PM2.5 绝对下降数值
  • 优良天数绝对增加天数
  • 单次过程的峰值精确数值
  • 全省/全市排名的具体名次

以上四项主要由气象年景与区域趋势决定，承诺即失真——这是本方案与同行“包效果”话术的根本区别。

效果验证三件套（每季末出评估页）

  • 去气象化趋势：用气象归一化方法剥离天气影响后看浓度变化，回答“人的功劳有几分”。
  • 邻县对照（双重差分）：同市、同天气的邻县是最天然的对照组——大家共享同一场风，差值即本地管控的净效果。此法不需要对方配合，公开数据可算。
  • 过程复盘对照：每轮过程与历史上同型、同强度过程比峰值与时长，逐轮积累样本，一季后即有可信结论。

试点退出条件：以一季（秋冬）为试点期。季末若去气象化与邻县对照两法均显示无正向差距、且临界天保良效果不达预期，则如实告知客户本模式在该县不成立，停续约、不拿天气好转冒充功劳。
